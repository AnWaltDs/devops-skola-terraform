# Answer

The provider is generated by `openstack.hcl`, the backend by `root.hcl`, and variables are not needed because Terragrunt passes inputs directly. Each include handles one concern.

Adding a second customer: copy `acme/` to `beta/` -- the path changes, so `name_prefix` and state path change automatically.

```
root.hcl       -> state + tags (everything)
customer.hcl   -> path anchor (per customer)
openstack.hcl  -> provider + defaults (per platform)
terragrunt.hcl -> env-specific values only
```
